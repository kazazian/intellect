# Cultural Intelligence Offer

Одностраничный сайт коммерческого предложения по программе "Культурный интеллект".

## Что внутри

- Три формата программы: игра, 5-часовой тренинг и полный день с сертификатом.
- Адаптивная верстка для desktop и mobile.
- Форма заявки с выбором формата.
- Sites entrypoint в `dist/index.js`.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте:

```text
http://127.0.0.1:4173/
```
