# Cultural Intelligence Offer

Одностраничный сайт коммерческого предложения по программе "Культурный интеллект".

## Что внутри

- Три формата программы: игра, 5-часовой тренинг и полный день с сертификатом.
- Адаптивная верстка для desktop и mobile.
- Форма заявки с отправкой в Google Таблицу.
- Sites entrypoint в `dist/index.js`.

## Подключение Google Таблицы

1. Создайте Google Таблицу.
2. Откройте `Расширения -> Apps Script`.
3. Вставьте код из `google-apps-script.js` и сохраните проект.
4. Нажмите `Развернуть -> Новое развертывание`.
5. Тип: `Веб-приложение`.
6. Выполнять от имени: `Меня`.
7. У кого есть доступ: `Все`.
8. Скопируйте URL веб-приложения.
9. В `script.js` вставьте URL в строку:

```js
const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/...";
```

После этого новые заявки будут добавляться на лист `Заявки`.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте:

```text
http://127.0.0.1:4173/
```
